# Ads Multiplier — Interactive Workflow

An interactive team presentation of the proposed Frameo / Seedance 2.5 workflow.

- Seven workflow stages with the eight supplied videos.
- Optional clay motion reference, with the corrected 480 × 854 kitchen clip.
- Own-image or generated-asset choices and planned version count.
- Optional creative review, original-first editing and selective rollout.
- Optional narrated launch guide with three posting strategies.
- Decision flowchart, Helvetica typography and responsive presentation mode.

Open `index.html` locally, or use the GitHub Pages website.

The MP4s are unchanged copies of the supplied examples. This presentation does not generate, edit or automatically post videos. Step 5 describes a proposed stage; no example video was supplied for it.

## Navigation

Select Journey, Flow map or Why it matters. Use Present for the presentation layout, Left/Right arrow keys to move between stages and Escape to exit.
